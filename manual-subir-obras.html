Cómo subir tus obras a la web

Cada vez que tengas un dibujo nuevo, son tres movimientos. No hace falta tocar código.

Movimiento 1ArrastrarPoné la imagen en la carpeta de su categoría.
Movimiento 2NombrarEl nombre del archivo es la ficha de la obra.
Movimiento 3Doble clic en subir.batProcesa y publica. En ~1 minuto está online.

Dónde va cada cosa

La carpeta es la categoría

Todo vive dentro de contenido/. Donde pongas la imagen, ahí queda categorizada. Los filtros de la galería se arman solos a partir de estas carpetas.

contenido/
├── obras/
│   ├── personajes/      ← Personajes / Retratos
│   ├── concept-art/     ← Concept Art / Entornos
│   ├── editorial/       ← Ilustración Editorial
│   ├── bocetos/         ← Bocetos
│   ├── dibujos-a-mano/  ← Dibujos a mano / fotos de cuadernos
│   └── (tu carpeta nueva)/  ← crea un filtro nuevo automáticamente
├── hero/            ← 1 imagen: la portada de la web
└── proceso/
    └── Nombre de la obra/   ← 1_boceto, 2_linea, 3_render, 4_final

¿Categoría nueva? Creá una carpeta dentro de obras/ (por ejemplo bocetos) y arrastrá ahí las imágenes. El filtro aparece solo, con el nombre de la carpeta. Para que tenga un nombre más lindo, agregalo en contenido/categorias.json (abrilo con el Bloc de notas y seguí el formato de las líneas que ya están).

La ficha va en el nombre

Cómo nombrar cada obra

El nombre del archivo lleva los datos separados por doble guión bajo (__, dos veces la tecla de guión bajo, sin espacios alrededor):

Título__Software__Año__Cliente.png

TítuloSíComo quieras que se lea. Con acentos y espacios está bien.

AñoRecomendada4 cifras: 2025.
ClienteNoSolo si hubo cliente o proyecto. Si no, no pongas nada (ni el __ final).

Constructor de nombres

Completá los datos y copiá el nombre. Después renombrá tu archivo con eso (tecla F2 sobre el archivo).

Cada vez que subas obras

Paso a paso

  1. Guardá tu dibujo terminado

    PNG o JPG están perfectos. No hace falta achicarlo ni comprimirlo: la web genera sola las versiones livianas.

  2. Ponele el nombre correcto

    Usá el constructor de arriba o seguí el formato Título__Software__Año__Cliente.

  3. Arrastralo a la carpeta de su categoría

    Dentro de contenido/obras/: personajes, concept-art, editorial, bocetos o dibujos-a-mano (fotos de cuadernos y papel). Podés arrastrar muchas imágenes juntas.

  4. (Opcional) Mirá cómo queda

    Doble clic en ver-web.bat y se abre la web en tu compu. Si no te gusta algo, corregilo y se actualiza sola. Cerrá la ventana negra para detenerla.

  5. Doble clic en subir.bat

    Abre una ventana negra: procesa las imágenes, te avisa si algún nombre está mal, y publica. Cuando dice “Listo”, esperá aproximadamente 1 minuto y recargá la web.

Si al procesar aparece un aviso amarillo o rojo, leelo: dice exactamente qué archivo está mal y cómo debería llamarse. Las demás obras se publican igual.

Lo que más miran los estudios

Mostrar tu proceso

Creá una carpeta dentro de contenido/proceso/ con el nombre de la obra y metele las etapas numeradas. La web arma sola el comparador boceto ↔ final y una tira con las etapas. Solo imágenes: sin textos ni descripciones.

contenido/proceso/Retrato de Ana/
├── 1_boceto.png     ← el “antes” del comparador
├── 2_linea.png      ← etapa intermedia
├── 3_render.png     ← etapa intermedia
└── 4_final.png      ← el “después” del comparador
  • Mínimo 2 imágenes (la primera es el “antes” y la última el “después”). Ideal: 4.
  • Usá el mismo tamaño y proporción en todas las etapas para que el comparador calce perfecto.
  • Podés tener 2 o 3 obras de proceso: una carpeta por obra. El nombre de la carpeta es el título que se muestra.

Tus textos, con tus palabras

Cómo redactar “Sobre mí”

Todo el texto de la sección “Sobre mí” vive en un solo archivo: contenido/sitio.ts. Se edita a mano con el Bloc de notas (o VS Code), sin programas ni inteligencia artificial. Guardás, corrés subir.bat y la web se actualiza.

Paso a paso

  1. Abrí el archivo

    Clic derecho sobre contenido/sitio.ts → Abrir con → Bloc de notas.

  2. Buscá sobreMi

    Con Ctrl + F. Vas a ver una lista de párrafos entre corchetes [ ].

  3. Escribí un párrafo por línea

    Cada párrafo va entre comillas dobles "…" y termina con una coma. Para agregar un párrafo, copiá una línea completa y cambiale el texto. Para quitar uno, borrá la línea entera.

  4. Guardá y publicá

    Ctrl + S y doble clic en subir.bat. Para verlo antes en tu compu, usá ver-web.bat.

sobreMi: [
  "Soy ilustrador digital. Trabajo en personajes y fondos para videojuegos.",
  "Participé en el desarrollo de Space Hunters, donde diseñé personajes y escenarios.",
  "Trabajo por encargo y en equipo. Escribime para contarme tu proyecto.",
],

Consejos para escribirlo

  • Corto y en primera persona: 2 a 4 párrafos de 1 a 3 frases. Quien mira un portfolio lee poco.
  • Qué hacés, con qué y para quién: primero tu especialidad, después un proyecto concreto (por ejemplo Space Hunters), y al final cómo contactarte.
  • Datos reales: nombres de proyectos, años y software que de verdad usaste. Evitá frases vagas como “apasionado por el arte”.
  • Corrección: leelo en voz alta antes de publicar y revisá tildes y nombres propios.

Cuidado con las comillas y las comas. Si el texto lleva comillas adentro, usá comillas simples '…' o las comillas tipográficas “ ”. Una comilla doble " suelta corta el texto. Tampoco borres los corchetes [ ], las comas del final ni las comillas de apertura y cierre. Si te equivocás, la web no compila y GitHub Actions muestra una cruz roja: deshacé el último cambio con Ctrl + Z, guardá y volvé a correr subir.bat.

Cambios después de publicar

Borrar, reemplazar y reordenar

  • Borrar una obra: eliminá el archivo de su carpeta y doble clic en subir.bat. Desaparece de la web.
  • Corregir el título, software o año: renombrá el archivo (F2) y corré subir.bat.
  • Cambiar la imagen: reemplazá el archivo por el nuevo con el mismo nombre y corré subir.bat.
  • Cambiar el orden: agregale un número al principio del nombre (01_, 02_…). Las obras con número van primero, en ese orden.
  • Mover de categoría: arrastrá el archivo a otra carpeta de obras/.
Si algo no sale como esperabas

Problemas frecuentes

Subí una obra y no aparece en la web

Esperá 1–2 minutos y recargá con Ctrl + F5. Si sigue sin aparecer, fijate en la ventana negra de subir.bat: si hay líneas rojas, ese archivo tiene el nombre mal (te dice cómo corregirlo).

También revisá en GitHub, pestaña Actions, que la última ejecución tenga el tilde verde.

Me sale un aviso amarillo sobre un archivo

Es un aviso, no un error: la obra se publica igual, pero le falta algún dato (software o año). Renombrá el archivo con el formato completo y volvé a correr subir.bat.

Aparece “Ejemplo …” en mi galería

Son obras de muestra. Borrá los archivos que empiezan con “Ejemplo” de contenido/obras/ y la carpeta Ejemplo … de contenido/proceso/.

Una imagen pesa muchísimo o GitHub la rechaza

GitHub no acepta archivos de más de 100 MB. Exportá la obra final como PNG o JPG de hasta unos 4000 px de lado (menos de ~25 MB). Para la web es más que suficiente: el sitio usa como máximo 2200 px.

La primera vez me pide usuario o contraseña de GitHub

Es normal la primera vez que subís desde esa compu: iniciá sesión en la ventana que se abre y no te vuelve a pedir nada.

Se cierra la ventana negra y no alcancé a leer

No debería: subir.bat espera una tecla al final. Si igual pasa, abrí una terminal en la carpeta del proyecto y corré npm run obras para ver el detalle.
